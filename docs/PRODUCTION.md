# Liaper: вывод в продакшн

Дата: 22 октября 2026. Документ описывает, что изменено для боевого запуска, как развернуть сервер и что остаётся сделать до приёма реальных пользователей.

## Что исправлено в безопасности

| Было | Риск | Стало |
| --- | --- | --- |
| Админы по умолчанию `napsy,admin`; первый вошедший задаёт мастер-пароль | Любой регистрирует `@admin` и получает админку | Админов нет, пока не задан `LIAPER_ADMIN_USERNAMES`; мастер-пароль от 12 символов |
| Пароли: один SHA-256 с солью, минимум 4 символа | Быстрый перебор утёкших хешей | Argon2id, минимум 8 символов; старые хеши проверяются и прозрачно обновляются при входе |
| `POST /api/nodes/heartbeat` без авторизации | Подмена медиа-ноды и перехват всех звонков | Требуется `Bearer LIAPER_NODE_SECRET` (сравнение за постоянное время) |
| SFU пускал в комнату любой `room_id`/`user_id` | Подслушивание урока, выкидывание участника подменой id | Сервер выдаёт подписанный допуск на 2 минуты (`POST /api/rooms/:id/sfu-ticket`) только участникам; нода проверяет комнату, пользователя и свой id |
| Нода пересылала кадры в любую комнату из пакета | Вброс видео/звука в чужой урок | Пересылка только в комнату, в которую выполнен вход |
| `/api/users`, `/api/users/search`, `/api/nodes` открыты | Выгрузка всего каталога пользователей и инфраструктуры | Каталог — только админу; поиск — по началу ника от 3 символов, до 10 результатов; ноды — после входа |
| Ответ «пользователь не найден» при входе | Перебор существующих ников | Единое «Неверный @ник или пароль» и выравнивание времени ответа |
| Выход не отзывал токен, токены бессрочные | Украденный токен работает вечно | `POST /api/auth/logout` удаляет сессию; сессии старше 30 дней удаляются при запуске |
| Жалоба на любую комнату | Снимок чужой переписки в админке | Только участник комнаты или личного диалога |
| Групповой урок мог создать ученик | Нарушение ролей | Только репетитор (проверка на сервере, тест) |
| CORS `permissive` | Запросы с любых сайтов | `LIAPER_ALLOWED_ORIGINS` задаёт список; без него — режим разработки с предупреждением |
| Postgres на `0.0.0.0:5432` с паролем по умолчанию | Доступ к базе из интернета | Порт только на `127.0.0.1`, пароль обязателен |
| Контейнеры от root | Повышение привилегий при уязвимости | Пользователь `10001`, read-only FS, `no-new-privileges` |
| Нет CSP и заголовков безопасности; Tauri `csp: null` | XSS без ограничений | CSP, `X-Frame-Options`, `nosniff`, `Referrer-Policy`, `Permissions-Policy` в nginx; CSP в Tauri |
| Android: cleartext во всех сборках, релиз подписан debug-ключом | Перехват трафика, неподдерживаемые обновления | HTTP только в debug; релиз подписывается ключом из `android/key.properties` |
| Регистрация: общий лимит 12 в 10 минут | Бот забивает лимит, и регистрация закрывается для всех | Proof-of-work (`GET /api/auth/challenge`, 17–21 бит, растёт при наплыве), одноразовые подписанные задачи; 20 попыток регистрации и 60 попыток входа с IP; общий лимит 300 в 10 минут |
| Один аккаунт на двух устройствах: оба подключались к звонку и выбивали друг друга | Обрывы звонка, «выход» не с того устройства | Звонок привязан к устройству; на остальных плашка «Урок идёт на другом устройстве» с переносом |

Тесты: подпись допусков SFU, Argon2id и миграция старых хешей, запрет создания урока учеником, proof-of-work и IP за прокси, звонок на двух устройствах — в `cargo test --workspace`.

## Развёртывание

1. DNS: домен (например, `lessons.example.com`) указывает на сервер; открыты порты 80 и 443.
2. `cp .env.example .env` и заполните секреты (`openssl rand -base64 48` для каждого):
   `POSTGRES_PASSWORD`, `LIAPER_STORAGE_SECRET`, `LIAPER_NODE_SECRET`, `LIAPER_DOMAIN`, `LIAPER_ALLOWED_ORIGINS`, `LIAPER_ADMIN_USERNAMES`, адреса `FILE_NODE_PUBLIC_URL`, `NODE_1_WS_URL`, `NODE_2_WS_URL`.
3. На Linux: `sudo chown -R 10001:10001 data releases`.
4. Запуск с TLS через Caddy (сертификат выпускается автоматически):

```bash
docker compose --profile tls up -d --build
```

Caddy раздаёт: `/` — сайт и лендинг, `/api` и `/ws` — сервер управления, `/sfu/1`, `/sfu/2` — медиа-ноды, `/files` — файловая нода.

5. Зарегистрируйте аккаунт администратора с ником из `LIAPER_ADMIN_USERNAMES` и задайте мастер-пароль в админке (`#admin`).
6. Android: `flutter build apk --release --dart-define=LIAPER_SERVER_URL=https://lessons.example.com` с настроенным `android/key.properties`:

```properties
storeFile=/абсолютный/путь/liaper-release.jks
storePassword=...
keyAlias=liaper
keyPassword=...
```

## Перед приёмом реальных пользователей

| Приоритет | Что | Почему |
| --- | --- | --- |
| P0 | Шифрование медиа звонков | Видео и звук идут через SFU как JPEG/PCM в Base64 без шифрования. Переписка и файлы шифруются на устройстве, звонки — только TLS до сервера. Не заявляйте «сквозное шифрование звонков» |
| P0 | Ключ подписи обновлений Tauri | В `tauri.conf.json` стоит пример публичного ключа и `http://127.0.0.1` в адресе обновлений: сгенерируйте ключ (`npx tauri signer generate`), подставьте pubkey и HTTPS-адрес |
| P1 | TURN-сервер (coturn) | Без него часть пользователей за NAT/мобильным интернетом не подключится; переменные `LIAPER_TURN_*` уже прокинуты в ноды |
| P1 | Резервные копии | Ежедневный `pg_dump` и копия `data/files` вне сервера |
| P1 | `LIAPER_TRUSTED_PROXY_HOPS` | Лимиты по IP верны, только если число прокси указано точно: 2 с Caddy, 1 без него. Иначе все пользователи попадут в один IP прокси или адрес можно будет подделать |
| P1 | Политика конфиденциальности и согласие | Сервис для учеников, в том числе несовершеннолетних: нужны документы и согласие родителей (152-ФЗ) |
| P2 | Мониторинг | Сбор логов, алерты на `GET /api/health`, место на диске файловой ноды |
| P2 | Хранение токенов | Токены сессий лежат в базе открыто; лучше хранить хеш |
| P2 | Проверка на физических устройствах | Звонок Android ↔ Web ↔ Windows, поворот экрана, смена сети, урок 60 минут |
